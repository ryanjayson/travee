## 2. Functional Requirements

Implement per `PRD.md`. Technical obligations:

1. **Offline-first is a hard requirement.** All reads/writes hit WatermelonDB first. Network is optional and must never block a user action.
2. **Local DB is the source of truth.** UI reads via feature hooks → local services → WatermelonDB. API services (`src/services/api`, `src/services/travel/_travelApi.ts`) are secondary.
3. **Schema changes require a WatermelonDB migration** (see `src/db/migrations.ts` and ARCHITECTURE).
4. **Type-specific activity details** are stored in dedicated tables keyed by `activity_id`.
5. **JSON columns** (destination_data, images, attachments, custom_tags) must be serialized/parsed via `src/utils/safeJsonParse.ts`.
6. **Every feature is a module** under `src/features/<Feature>` with `screens/`, `components/`, `hooks/`, `types/`, `utils/`.

## 3. Non-Functional Requirements

| Area | Requirement |
|------|-------------|
| Performance | 60/120fps UI thread animations (`useNativeDriver`/Reanimated); `expo-image` hardware caching; list virtualization; `expo-haptics` for tactile feedback; no sync DB work on render |
| Offline & Edge Cases | Full CRUD without network; 4 UI states (Data, Empty with CTA, Loading, Error with retry); sanitize invalid dates and (0,0) coordinates |
| Startup | DB init and PostHog init must not block first paint |
| Reliability | Global error handler + ErrorBoundary + persistent error logs (rotation at 500 rows) |
| Security | See `SECURITY.md`; secrets never in source; sensitive prefs in `expo-secure-store` |
| Accessibility | Touchables need `accessibilityRole="button"` and labels for icon-only controls |
| Observability | Structured `errorLogger` (category + severity) and PostHog events with opt-out |
| Compatibility | iOS + Android parity: hardware `BackHandler` vs edge swipe `beforeRemove`, `elevation` vs iOS `shadow*`, platform-aware `KeyboardAvoidingView` |

## 4. Environment & External Services

Loaded via `react-native-dotenv` from `.env` (git-ignored):

| Var | Use |
|-----|-----|
| `API_BASE_URL` | REST base for travel endpoints |
| `GOOGLE_MAPS_API_KEY` | Places / geocoding |
| `MAPBOX_ACCESS_TOKEN` | Mapbox tiles / static maps |
| `POSTHOG_API_KEY` | Analytics (optional; disabled if missing) |
| `POSTHOG_HOST` | Analytics host (default `https://us.i.posthog.com`) |

Never commit `.env` or `.env*.local`. Never log secret values.

## 5. Constraints

- `react-native.config.js` excludes `@react-native-ml-kit/text-recognition` from iOS.
- `overrides.lightningcss` pinned to `1.30.1`.
- WatermelonDB is used with `jsi: false`.
- Native folders (`/ios`, `/android`) are git-ignored and generated by Expo prebuild.
- Path alias: `@/* → ./src/*` (tsconfig + Jest mapper).

## 6. Definition of Done

A change is done only when all are true:

- [ ] Behavior matches `PRD.md`; technical approach matches this TRD.
- [ ] TypeScript compiles with no new errors (`npx tsc --noEmit`).
- [ ] Tests added/updated and passing (`npm test`).
- [ ] No hardcoded colors; theme/Paper tokens used.
- [ ] Errors handled via `errorLogger` where relevant; no raw `console.log` in production paths.
- [ ] DB schema change includes a migration.
- [ ] Relevant docs updated (PRD/TRD/ARCHITECTURE/CHANGELOG) and, if significant, DECISIONS.md.
